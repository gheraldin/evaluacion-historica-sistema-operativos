# Tercera Generación de Sistemas Operativos
## Periodo: 1970 - 1980
Durante esta generación se produjo un importante avance en los Sistemas Operativos. Las computadoras comenzaron a utilizar circuitos integrados, lo que permitió crear equipos más pequeños, rápidos y eficientes.
También aparecieron técnicas como la multiprogramación y el tiempo compartido.
## Características
- Uso de circuitos integrados.
- Multiprogramación.
- Sistemas de tiempo compartido.
- Mayor eficiencia del procesador.
- Mejor administración de memoria.
- Mayor interacción entre el usuario y la computadora.
## Multiprogramación
La multiprogramación permite mantener varios programas en memoria y utilizar el procesador para ejecutar diferentes tareas.
Cuando un programa necesita esperar una operación, el procesador puede trabajar con otro programa.
## Tiempo compartido
El tiempo compartido permite que varios usuarios utilicen los recursos de una computadora de manera aparentemente simultánea.
## Ejemplo
Uno de los sistemas más importantes de esta época fue UNIX, desarrollado inicialmente en los laboratorios Bell.
## Importancia
Esta generación estableció muchas características que todavía se utilizan en los Sistemas Operativos actuales.
## Conclusión
La tercera generación fue fundamental para mejorar el rendimiento y permitir que varios programas y usuarios utilizaran los recursos de una computadora de manera más eficiente.
